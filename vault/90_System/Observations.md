# Observations

本頁記錄「可能需要成為規則，但證據還不夠」的反覆現象。Observation 不是正式 Schema。

## 升級門檻

一項觀察通常在以下條件成立時才提出 System Decision：

- 同類問題至少重複出現約 3 次，或單次風險很高。
- 已造成搜尋、理解、證據或維護問題。
- 能寫成可檢查的規則。
- 新規則的成本低於持續人工處理。

次數是啟發式，不是硬性法律。
