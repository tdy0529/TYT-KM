# Sources Guide

10_Sources 保存已登記、需要長期引用的原始材料。它是證據層，不是理解層。

## 組織方式

- 先按登記年份放置，例如 10_Sources/2026。
- 每個來源取得唯一 ID：SRC-YYYY-NNNN。
- 建議檔名：SRC-YYYY-NNNN - 簡短來源名.ext。
- 原始材料的摘要、評析、摘錄與關聯，寫在 20_Knowledge/Source Notes，不直接混入原件。

## 不可變原則

完成登記後，原件原則上不可改寫。若來源更新：

- 保留舊版並登記新版，或
- 明確標記版本、替代關係與擷取日期。

任何刪除、搬移或改寫已登記來源的操作，都需要使用者確認。

## 來源不等於知識

來源提供可追溯證據；Source Note 表示我們如何讀它；Knowledge Note 表示跨來源後目前最可靠的理解。三者不能互相替代。

詳細流程見 [[90_System/Workflows]]；欄位定義見 [[90_System/Metadata Schema]]。
